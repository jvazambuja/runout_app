How to Prepare Input Files using QGIS

This application requires topographic and rupture plane data formatted as simple text files containing XYZ coordinates. If you have a `.dxf` file (commonly generated by CAD software or drone surveys), you can convert it to the required format using QGIS, a free and open-source Geographic Information System.

Step-by-Step Conversion

  1. Import the DXF into QGIS
    Open QGIS. Drag and drop your `.dxf` file directly into the main workspace. When prompted, select the vector layers that contain your elevation contours or points.
  2. Extract Vertices
    If your DXF contains contour lines or polygons, you need to break them down into individual points.
    Go to the top menu: Vector > Geometry Tools > Extract Vertices. Select your imported layer and click Run.
  3. Add X, Y, and Z Attributes
    The newly created "Vertices" layer has geometric points, but their coordinates are not yet written into a readable data table.
    Go to: Vector > Geometry Tools > Add Geometry Attributes. Select the Vertices layer and click Run. This creates a new layer with the exact X, Y, and Z values explicitly calculated for every point.
  4. Export to Text/CSV
    In the Layers panel on the left, right-click the "Added geom info" layer and select Export > Save Features As...
  5. Configure the Export Format
    In the export window, set the Format to Comma Separated Value [CSV].
    Under Layer Options, look for the SEPARATOR field and ensure it is set to COMMA.
    Under Select fields to export, uncheck everything except the new xcoord, ycoord, and zcoord columns.

Final File Format

Once exported, you can rename the `.csv` file to `.txt` if you prefer. The application expects the data to look like this:

x,y,z
501234.12, 6789012.34, 150.5
501235.50, 6789013.00, 150.2
...

You can repeat this exact process to draw and export your 2D Rupture Section line.
