Methodology & Calculations

This application utilizes a geometric mass-conservation approach for initial volume and an empirical angle-of-reach model for runout limits.

  • Volume Calculation: The initial failure mass is computed by projecting the 2D rupture plane transversely. The lateral limits are defined by daylighting the surface against the topography at the specified Basal Friction Angle.
  • Footprint Limit (Angle of Reach): The absolute maximum boundary of the runout zone is calculated using the H/L angle-of-reach ratio evaluated using the highest source elevation (H) and the farthest deposit length (L)[cite: 1, 2]. Movement halts where the topography intersects this mathematical arctan(H/L) boundary.
  • Volume Compatibility & Repose: Inside the H/L footprint boundary, a true 3D deposit volume is reconstructed. A geometric capacity model inward-scales the deposit thickness such that final runout volume equals the initial volume. Slopes from the boundary inward are strictly prevented from overcoming the specified Deposit Angle of Repose.

Data Preparation (QGIS Tutorial)

This application requires topographic and rupture plane data formatted as simple text files containing XYZ coordinates. If you have a `.dxf` file (commonly generated by CAD software or drone surveys), you can convert it to the required format using QGIS.

  1. Import the DXF into QGIS: Drag and drop your `.dxf` file directly into the main workspace. Select the vector layers that contain your elevation contours or points.
  2. Extract Vertices: Go to the top menu: Vector > Geometry Tools > Extract Vertices. Select your imported layer and click Run.
  3. Add X, Y, and Z Attributes: Go to: Vector > Geometry Tools > Add Geometry Attributes. Select the Vertices layer and click Run. This creates a new layer with the exact X, Y, and Z values explicitly calculated for every point.
  4. Export to Text/CSV: In the Layers panel on the left, right-click the "Added geom info" layer and select Export > Save Features As...
  5. Configure the Export Format: Set the Format to Comma Separated Value [CSV]. Under Layer Options, ensure SEPARATOR is set to COMMA. Under Select fields to export, uncheck everything except the new xcoord, ycoord, and zcoord columns.

Once exported, you can rename the `.csv` file to `.txt`. The application expects the data to look like this:

x,y,z
501234.12, 6789012.34, 150.5
501235.50, 6789013.00, 150.2
...
