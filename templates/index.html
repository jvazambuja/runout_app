Numerical Runout Propagation Architecture

This model utilizes a dual-resolution geometric approach to simulate landslide mass propagation, incorporating dynamic topographic routing and kinematic energy limits.

1. Dual-Resolution Spatial Discretization

To maximize computational efficiency without sacrificing physical accuracy, the model decouples the topographic mesh from the source material mesh:

  • Topographic Grid: The raw point cloud is dynamically remeshed into a continuous, structured grid using linear interpolation. This guarantees robust surface gradient calculations.
  • Source Grid: The failure plane footprint is rigidly discretized at a strict 0.5m interval. This high-definition matrix ensures volumetric conservation and acts as the independent source points for the ray-tracing algorithm.
2. Kinematic Flow Routing (Steepest Descent with Momentum)

Unlike simplistic line-of-sight models that fail in complex valleys, this algorithm routes each discretized source cell independently using topographical gradient descent. To simulate geophysical inertia and prevent unrealistic stopping on flat plateaus or sudden zigzagging, a momentum blending factor is applied:

  • Gradient Tracking: At each timestep, the local Δz/Δx and Δz/Δy dictate the theoretical flow direction.
  • Vector Blending: The active travel vector is computed as Vnew = 0.6(Gradient) + 0.4(Vold), smoothing the path through complex channels.
  • Inertia: If the local gradient drops below a critical threshold (e.g., flat terrain), the mass preserves its preceding trajectory until the energy limit is exhausted.

Figure 1: Plan view demonstrating momentum-based flow routing vs. direct geometric projection.

3. Energy Limits and Angle of Reach Envelopes

The travel distance of each independent flow path is strictly governed by the Angle of Reach (H/L), evaluated continuously along the 3D curvilinear path length. When the local elevation of the routed path exceeds the geometric reach limit, the trace halts.

To reconstruct the final deposit, a Convex Hull algorithm computes the minimal enclosing polygon (envelope) containing all terminal stopping points. This guarantees a continuous, smooth deposit boundary that bridges numerical gaps caused by path divergence.

File Preparation Tutorial (QGIS Workflow)

To run the simulation, you must provide two properly formatted CSV or TXT files: one for the topography and one for the rupture axis. Both files must contain explicitly defined x, y, z headers in the first row. You can easily prepare these files from standard CAD DXF formats using QGIS.

1. Topography File (dem_mesh.csv)

This file defines the base terrain. Follow these steps to convert a topographic DXF mesh into the required format using QGIS:

  1. Import DXF: Drag and drop your topographic DXF file into QGIS. Select the appropriate vector layers containing the 3D elevation data (usually lines or 3D polygons).
  2. Extract Vertices: Open the Processing Toolbox (Ctrl+Alt+T) and search for Extract vertices. Run this tool on your DXF layer to convert the continuous geometry into individual point data.
  3. Add Geometry Attributes: In the Processing Toolbox, search for Add geometry attributes. Run this tool on the newly created "Vertices" layer. This calculates the exact spatial coordinates and adds them to the attribute table.
  4. Export to CSV: Right-click the resulting layer with the added attributes in the Layers panel and select Export > Save Features As...
  5. Format Settings:
    • Format: Comma Separated Value [CSV]
    • Under the Select fields to export and their export options section, uncheck everything except the newly generated X, Y, and Z coordinate fields.
    • Ensure the exported file uses a comma separator.
  6. Final Check: Open the exported file in a text editor or spreadsheet software and ensure the headers are exactly x, y, z.
Format Example:
x,y,z
500120.5,6300450.2,450.0
500125.5,6300450.2,448.5
500130.5,6300450.2,447.1
...
2. Rupture Axis File (rupture_section.csv)

This file defines the 2D longitudinal baseline of the initial failure mass. You can use the exact same QGIS workflow described above on a DXF containing a single 3D polyline representing the rupture axis.

  • The drawn line must be strictly ordered sequentially from the crest (highest elevation) down to the toe (lowest elevation) of the failure.
  • When drawing the polyline in CAD before exporting to DXF, ensure the vertices represent the absolute deepest expected failure plane elevation at that specific X/Y coordinate.
Format Example:
x,y,z
500150.0,6300480.0,460.0    <-- Crest (Start)
500155.0,6300485.0,455.0
500160.0,6300490.0,452.0
500165.0,6300495.0,450.0    <-- Toe (End)
